# Sort Animation (Work in progress)

I am currently working on a project for visualizing sorting **algorithms**. I am using `pygame` for rendering the interface since I am **familiar** with this library. If you find any bugs, please let me know.

# How to Run It

* Open a terminal in the directory and **install** the dependencies:

```bash
pip install -r requirements.txt

```

* To run:

```bash
python bubble-sort-animation.py

```

> **Tip:** Use your `+` and `-` keys to change the speed of the animation.

# How to Change the Settings

* Open `bubble-sort-animation.py` using your preferred code editor.
* You **will see variable names that are self-explanatory, along** with the necessary instructions.
